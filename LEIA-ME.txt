# Plano de Corte MDF — Marcenaria Santos & Filho

## Publicar no GitHub Pages
1. Envie **todo o conteúdo desta pasta** para a raiz do repositório (não envie apenas o ZIP).
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)` e salve.
5. Aguarde o GitHub Pages publicar e abra o endereço HTTPS gerado no Safari do iPhone.

## Instalar no iPhone e preparar o offline
1. Com internet, abra o site publicado no Safari.
2. Aguarde alguns segundos para o cache offline ser instalado.
3. Toque em **Compartilhar → Adicionar à Tela de Início**. Se disponível, habilite a opção para abrir como app.
4. Abra pelo novo ícone enquanto ainda estiver conectado à internet pelo menos uma vez.
5. Depois disso, teste em modo avião.

O aplicativo faz os cálculos no próprio iPhone e não depende de conexão para calcular. O Service Worker armazena os arquivos do app para permitir a abertura offline após o primeiro carregamento bem-sucedido. A publicação de atualizações pode exigir abrir o app novamente com internet.

**Importante:** não apague os dados do Safari/site nem limpe os dados do site, pois isso pode remover o cache offline. Os dados salvos na lista usam o armazenamento local do navegador e podem não ser compartilhados entre Safari e o ícone instalado.

ÍCONES: os arquivos da pasta icons/ já usam o logotipo original da Marcenaria Santos & Filho.
Se já instalou uma versão anterior no iPhone, remova o atalho antigo da Tela de Início, abra a página atualizada no Safari e adicione novamente à Tela de Início para atualizar o ícone.


CORREÇÃO DE IMPRESSÃO PARA IPHONE
Esta versão usa a impressão nativa da própria página, sem abrir uma janela separada. Isso preserva os desenhos do plano (canvas) e evita bloqueios de janelas no iOS. Atualize TODOS os arquivos no GitHub, inclusive sw.js, para invalidar o cache anterior. No iPhone, abra o app com internet uma vez. Toque em Imprimir / PDF. Se o iOS não abrir a folha de impressão dentro do app instalado, abra a mesma URL no Safari e use Compartilhar > Imprimir; na prévia, amplie com dois dedos e use Compartilhar > Salvar em Arquivos para guardar o PDF.
